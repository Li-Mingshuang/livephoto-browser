## LivePhoto 浏览器 v0.1.0

Windows 上最好用的 iPhone Live Photo 浏览器。**绿色版单文件，双击即用。**

### 下载

下载下面的 `LivePhotoBrowser.exe`（约 4.5 MB），双击运行，填入你的照片文件夹路径即可。
也可以用环境变量直接进入：

```powershell
$env:LIVEPHOTO_OPEN="F:\DCIM"; .\LivePhotoBrowser.exe
```

### 环境要求

- Windows 10 1809+ / Windows 11
- WebView2 运行时（Win11 已内置）
- 微软的 *HEIF 图像扩展* 与 *HEVC 视频扩展*（多数品牌机预装）

### 这个版本的亮点

- **Live Photo 是真正的 Live**：悬停静音预览、点击/空格播放、切过去自动播、**带声音**、**零转码**
- **快**：17,159 个文件 257ms 扫完；网格滚动 58.5 fps 跑满 60Hz vsync；热缓存 14,896 张/秒
- **只读**：不导入、不建库、不复制，一张照片都不动
- **云端占位库也能秒开**：索引只读目录元数据，从不打开文件内容

### 已知限制

- HEIC 解码约 900ms/张且几乎不能并行（系统解码器限制），首次浏览大库时缩略图会逐个填充
- 翻页速度上限约 2~4.7 张/秒，超出时底部胶片条会显示"正在准备"
- 日期用文件修改时间，不是 EXIF 拍摄时间
- 滚动无惯性；只读浏览，v1 无编辑/导出

详细的性能数字与复现方式见仓库内 `docs/` 下的三份文档。
